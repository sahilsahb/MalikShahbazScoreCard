MALIK SHAHBAZ SCORE CARD - ANDROID PROJECT

This project builds an Android APK using GitHub Actions.

MOBILE BUILD STEPS:
1. Sign in to GitHub in your phone browser.
2. Create a new repository named MalikShahbazScoreCard.
3. Upload all files and folders from this project ZIP (including the hidden .github folder).
4. Open the repository's Actions tab.
5. Select "Build Malik Shahbaz Score Card APK".
6. Tap "Run workflow" if it has not started automatically.
7. Wait for the green successful check.
8. Open the completed workflow run and download the artifact named
   "Malik-Shahbaz-Score-Card-APK".
9. Extract the downloaded ZIP and tap app-debug.apk to install.

IMPORTANT:
- Never share your GitHub password or verification code with anyone.
- This is a debug APK for personal testing.
- The app screen works offline. Score data is currently kept in the app page
  while it remains open; export/long-term match saving can be added later.
